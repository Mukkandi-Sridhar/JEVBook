# Cover

Everything here is generated by the scripts in this folder, from the book's own palette and fonts
(`assets/fonts/`). Edit the scripts, not the SVGs or PDFs.

## Files

| File | What it is |
|---|---|
| `print/cover-paperback.pdf` | KDP paperback wrap (back, spine, front), 7 × 10 in trim, 0.125 in bleed. Upload this. |
| `print/cover-hardcover.pdf` | KDP hardcover case-laminate wrap (wrap edge, hinges, boards). Upload this. |
| `print/cover-*-guides.pdf` | The same wraps with the guides layer: trim or board lines (cyan), spine lines, safe areas (magenta dashes), hinges, and the barcode area (yellow). For checking only. |
| `print/cover-*-preview.png` | PNG previews of the above; `cover-paperback-preview-grey.png` is the greyscale check. |
| `print/dimensions.json` | Page count, paper, spine width and full wrap size for each edition. |
| `ebook/cover.jpg` | Ebook front, 1600 × 2560 px. Also the EPUB cover (`_quarto.yml`). |
| `marketing/mockup-3d.png` | 3D book mockup, 2000 × 1400 px. |
| `marketing/post-square-1080.png` | Square social post, 1080 × 1080 px. |
| `concepts/` | The three first concepts (a typographic, b converging streams, c reliability diagonal; A was chosen), and the refinement of A: `v0-*` (the first release's front, the fallback) and `v1-*` to `v3-*`, each at full size, 150 px and 80 px, in colour and greyscale; `variants.json` (title share, contrast, greyscale levels, five-second sentences) and `compare.png` (all four side by side). v1 is the front in use. |
| `src/` | The SVG sources the PDFs and PNGs are rendered from, plus the front and spine PNGs the mockup uses. |
| `checks.json` | The last run of `check.py`: contrast, spelling and PDF sizes. |

## Rebuild

Needs Python with Pillow, pypdf, segno and pyspellchecker, `pdfinfo` and `pdftotext` (poppler), and Node with
Playwright's Chromium (`render.mjs` looks for a global install). Render the book first: the page count comes from
the interior PDF in `_book/`, and the figure count for the front strap line from its captions.

```bash
python3 cover/concepts.py   # three concepts + tests  -> cover/concepts/
python3 cover/variants.py   # v0-v3 fronts, tests, compare.png -> cover/concepts/
python3 cover/wrap.py       # print wraps, ebook, front -> cover/print, cover/ebook, cover/src
python3 cover/mockup.py     # 3D mockup and square post -> cover/marketing
python3 cover/check.py      # contrast, spelling, sizes -> cover/checks.json
```

Rebuild after any change to the page count: the spine width follows it.

## Changing the front

`FRONT` at the top of `wrap.py` picks the front from `variants.py`: `"v1"` (in use) or `"v0"` (the first
release's front, with the purple act / review / escalate bar). Rerun `wrap.py`, `mockup.py` and `check.py`.

## Changing the paper

`PAPERBACK_PAPER` and `HARDCOVER_PAPER` at the top of `wrap.py` choose the paper; the thickness per page is in
`PAPER` in `coverlib.py`:

| Paper | Inches per page |
|---|---|
| `bw_white` | 0.002252 |
| `bw_cream` | 0.0025 |
| `standard_color` | 0.002252 |
| `premium_color` | 0.002347 |

Before uploading, download KDP's cover template for the final page count and paper, and lay it over the guides PDF.
KDP's calculator couldn't be reached from this build (see DECISIONS.md, D-75).

## Placeholders to fill

The back cover has no photo; the bio is `AUTHOR_BIO` in `wrap.py`. Left to fill:

- The ISBN barcode: KDP prints it in the bottom-right 2 × 1.2 in area, which is kept empty (it's marked only on the
  guides layer). If you supply your own barcode, place it there.

Prices aren't printed on the cover; set them in KDP.

## Switches in `wrap.py`

- `SHOW_PRAISE` and `PRAISE`: the praise block under the blurb. It's off. When you have real, attributed endorsements,
  put them in `PRAISE` as `("quote", "Name, role")` pairs and set `SHOW_PRAISE = True`; `check.py` will then flag
  anything that no longer fits. Never fill it with invented quotes.
- `FRAGMENTS`: the small pieces of "Generate" beside the front title (`[]` for none).
- `DISCLAIMER`: the independence line under the author block.

`check.py` also checks that every item on the back sits inside the safe area, clear of the barcode area and of each
other, and that the before/after figures on the back match Chapter 18's table in the rendered book.
