# Research notes: Module 2

- Token premium: Petrov et al., NeurIPS 2023 (up to 15x between languages, 17 tokenizers); arXiv 2601.13328
  (Hindi, Bangla, Urdu 3-5x English). Exact counts depend on the model: measure with the provider's counter.
- Context rot: Chroma technical report, Hong, Troynikov, Huber, July 2025; 18 models; degradation with input length
  even on simple tasks.
- Temperature 0 nondeterminism: Thinking Machines Lab (Horace He), Sept 2025; cause is batch-size-dependent kernels;
  batch-invariant kernels give identical outputs at a speed cost.
- KV cache per token, 8B-class model with 32 layers, 8 KV heads, head dim 128, 2 bytes:
  2 x 32 x 8 x 128 x 2 = 131,072 bytes = 128 KB.
- Training memory ~16 bytes/parameter with mixed-precision Adam: Rajbhandari et al. 2020 (ZeRO).
- Llama 3: about 15T pretraining tokens (Meta, arXiv 2407.21783).
- Mixtral 8x7B: 46.7B total, 12.9B active per token (arXiv 2401.04088).
- Preference tuning side effects: sycophancy (Sharma et al. 2023); calibration drop after post-training (GPT-4
  technical report).
- Embedding storage: 1M x 1536 x 4 B = 6.1 GB; 1M x 384 x 4 B = 1.5 GB.
