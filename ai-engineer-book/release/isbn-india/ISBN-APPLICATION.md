## Short description (if the form asks for one)

Ship Real AI is a complete, practical path to becoming an AI engineer. It follows one system, a customer-support
assistant for an imagined Indian marketplace, from its first model call to a production service, across 17 modules:
how LLMs work, prompts and context, memory, tools and structured output, search and RAG, evals, decision models,
agents, guardrails and safety, MCP and agent protocols, long-running jobs, caching and cost, running in production,
and system design for interviews. Every number is measured or computed, costs are worked out in rupees, and every
code listing is run before it is printed.

## After the ISBN is allotted

Send me the number. I will put it on the copyright page, add an EAN-13 barcode to the back cover, and build the
India print files (interior and cover with the spine sized to your printer's paper), as was done for the last book
in `release/v1.0/print-india/`. Then, within 30 days of publication, send one copy each to the four legal-deposit
libraries (National Library Kolkata, Connemara Chennai, Asiatic Society Mumbai, Delhi Public Library).
